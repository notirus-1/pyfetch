installation instructions:
clone the repository with git
```console
$ git clone https://github.com/notirus-1/pyfetch.git
```
cd into the repo
```console
$ cd pyfetch
```
run pyfetch
```console
$ python pyfetch.py
```
or install it to be runnable from the terminal
```console
$ sudo mv pyfetch.py /usr/local/bin/
```
and run it with
```console
$ pyfetch.py
```
